    Gini?Gini 系数来自经济学，衡量不平等/集中度。
    0 = 完全平均（每桶用量一样）
    1 = 极度集中（一个桶占了全部）

    Burstiness B?Goh-Barabási 突发指数来自复杂网络，比较你的用量分布和泊松分布的差距。
    范围 [−1, +1]：
    • +1：极端突发（少数大爆发 + 大量空闲）
    • 0：泊松分布（事件随机均匀）
    • −1：完全均匀

    B > 0.15 算"明显突发"。你的值反映"忙起来很集中"。
    +1 极端突发，0 泊松

    top 5%?top 5% 集中度来自 Pareto 分析。
    把所有 30 分钟桶按 token 数从高到低排序，取最高的 5%（约 17 个桶），算它们贡献了总量的多少百分比。

    ≥ 25% 即为重尾分布。意味着省钱杠杆全在这 17 个高峰桶上。
    前 5% 桶占的份额

    Stickiness?黏性指数= P(活跃→活跃) − π(活跃)。
    衡量"活跃后继续活跃的概率"比"长期平均活跃率"高出多少。

    • 0：状态切换完全随机
    • +0.3：用起来停不下来
    • +0.5+：极强惯性

    反映 Markov 链的"自留倾向"。
    活跃后继续活跃的额外概率
    自相关 (ACF)?Autocorrelation Function测量"当前桶"与"N 桶之前的桶"有多相似。

    怎么读：
    • 短 lag 高（如 lag-30min） = 强持续性，下个 30 分钟还会用
    • lag-12h 负相关 = 反相，典型的"白天 vs 黑夜"
    • lag-24h 正相关 = 日周期
    • lag-7d ≈ 0 = 没有周周期

    范围 [−1, +1]，越接近 0 越独立。

    变化点检测 (30天)?Change-point detection 找时间序列中"前后均值显著不同"的拐点。

    方法：binary segmentation + BIC penalty。在每个候选位置切一刀，比较"切了之后 SSE 减少多少" vs "BIC 惩罚阈值"。超过阈值才接受。

    典型用途：检测"哪天起开始重度使用"。
    Markov 3态矩阵?状态转移矩阵 P[from][to]：行=当前状态，列=下个 30 分钟的状态，值=条件概率。

    三个状态：
    • I = Idle（0 token）
    • L = Low（<阈值）
    • H = High（≥阈值，阈值默认是活跃桶中位数）

    对角线（自留概率）越高越"沉浸"。

    每行加起来 = 1.00。

    工作流形状?5 个推断出的模式，全部从 Markov 矩阵的概率推断：
    • 升档难：P[I→H] 很小 = 启动很少猛干
    • 收工慢：P[H→I] 很小 = 高强度极少直接收工
    • 沉浸度：P[H→H] vs P[L→L] 谁大谁更黏
    • 升降对称性：|P[L→H] − P[H→L]|
    • Idle 黏性：P[I→I] + 平均停留时间
